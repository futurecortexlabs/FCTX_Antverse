## 1. 実装内容の要約

| 領域 | 実装 |
|---|---|

| 環境 | 霧と、視野に合わせて範囲を変える影（2 mm〜3 m）。カメラのガード（地表 + 0.1 mm + ニア面の距離） |

## 2. 合格基準の達成状況

基準は「アリスケールの地表が生成され、カメラを地面すれすれまで近づけても破綻しない」です。「破綻しない」を、次の 6 項目に分けて数値で検査しました。

| 項目 | 結果 | 数値 |
|---|---|---|
| アリスケールの地表の生成 | ✅ | 2 m 四方に、小石 1,041 個、落葉 396 枚、草 3,305 枚、粗砂粒（カメラ近くで約 1.6 万個）。生成は Node で 80 ms、ブラウザで 75 ms。被覆率は目標 30 / 30 / 50% に対し 29.4 / 29.1 / 48.7% |
| 穴・重なりがない | ✅ | 5 つの高さ × 4 地点のすべてで、描いたチャンクの面積の合計 = 描画範囲の面積、かつ親子の重複はゼロ。一部のチャンクが未生成の状態でも同じ |
| LOD 間の隙間 | ✅ | 1〜3 段違いの隣どうしで、実測した隙間はスカートの深さの 13.8% 以下 |
| 形状の正確さ | ✅ | 画面上の形状誤差は、全景・100 mm・10 mm・1 mm・0.2 mm のすべてで 2.00 px 以下。最も細かい段の誤差は、アリの目の高さ（1 mm）で 0.43 px、0.2 mm で 2.14 px |
| 描画 = シミュレーション | ✅ | 最も細かいチャンクの頂点の高さと `groundHeight` の差は 1e-5 mm 未満（float32 の丸め誤差のみ）。メッシュより細かい凹凸の陰影も、同じハッシュと振幅で描いている |
| 物体がめり込まない | ✅ | 落葉を土が突き抜けるのは 62,964 点中 2 点（0.003%、最大 0.04 mm）。小石・粒は葉の下に置かれない。草の根元は地表と 1e-9 mm 以内 |
| カメラが入り込まない | ✅ | 埋まった状態から始めた 3,000 か所すべてで、カメラは地表 + 0.15 mm 以上、注視点も地表以上になった |
| 性能 | ✅ | 8 視点すべて 60 fps（GPU 0.4–1.3 ms、メイン CPU 2.4–7.5 ms） |
| 再現性 | ✅ | 地形のダイジェスト `fbd7e07c` が Node とブラウザで一致。シミュレーションのハッシュ（10,000 tick）も `b5f928f2` / 別シード `7f802ed5` で一致。決定論の基準ハッシュは、地形を状態に加えたため `18c1b820` → `dacfd1de` に意図的に更新した |

## 5. Phase 2 に進む前に判断していただきたいこと

1. **Phase 2 の範囲**: 合格基準は「三脚歩行で凹凸を歩き、脚がめり込まない・浮かない」です。次のように進めることを提案します。
   - 足が乗るのは `supportHeight` の面（土・粒・小石・落葉）。**草の葉を登る（垂直面・裏面の歩行）は Phase 2 の範囲外**とし、後のフェーズに回す。
   - 「めり込まない・浮かない」は、立脚中の足先と面の距離が ±0.02 mm 以内であることで数値判定する。
2. **シミュレーションの並列化の時期**: 地形の問い合わせだけで、1 万体の 1 tick が 12.5 ms（ブラウザ）になりました。歩行では胴体の姿勢を求めるのに問い合わせが数回必要になります。Phase 0 では「Phase 3 の後」を推奨しましたが、**Phase 2 で Worker の並列化（設計済みの段階分割）も行う**ことを推奨に変更します。
   脚の関節は当初の設計どおり描画側で IK を解き、カメラ近くの個体（LOD0）だけを計算します。
3. **形態データ**: 脚の節の長さや体節の比率について、*F. japonica* の実測値は手元にありません。ASM-SPC-001 の方針どおり、*Formica* 属の形態計測の文献で補います。標本写真や実測値を提供していただける場合は、それを優先します。
4. **2 m 四方の外側**: 物体を置くのは 2 m 四方だけで、その外側は土の起伏だけです（全景では境界が見えます）。Phase 7（環境）までこのままでよいかを確認させてください。

## 補足

- 開発中、Vite のファイル監視が編集を取りこぼし、古いモジュールが配信されることが 1 度ありました（Windows）。開発サーバーを再起動すると直ります。報告用のスクリーンショットと計測値は、すべて再起動後に取得しました。
- WebGL2 では、細部のシェーダー（符号なし整数のハッシュ）が動作し、50 fps で起動することを確認しました。性能スイープは WebGPU だけで行いました。
- 見た目の既知の点: 0.12 mm の細砂粒の斑点は凸型のドームとして陰影をつけています（光の向きと陰影の対応は確認済み）。ただし、太陽を背にした視点では凹んだ穴に見える錯視が残ります（スクショ 07・08）。見た目だけの値（ENG-REN-010 の `soilSpeckle*`）なので、気になる場合は弱められます。
