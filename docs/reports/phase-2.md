## 1. 実装内容の要約

| 領域 | 実装 |
|---|---|
| 体のつくり | 頭部（複眼・大あご）・中胸・鱗片状の腹柄節・腹部、膝状の触角（柄節 + 鞭節）、6 本の脚（基節・腿節・脛節・跗節）。寸法は体長比のパラメータ |
| 探索歩行 | 相関ランダムウォーク（旋回の角速度が OU 過程）。個体ごとに速度がばらつく。触角の届く距離の前方で ±1.4 mm を超える段差を探り、その場で旋回して避ける。アリーナの縁でも同様に旋回する |
| 胴体の姿勢 | 中胸・頭部・腹部の下の足場から体高とピッチを、地面の傾きからロールを決め、時定数 0.05 s で追従。各体節の下面は足場より下に入らない |
| 脚 | 交互三脚歩容。立脚中は足を固定し、遊脚は地表より下に入らない円弧を描く。足場は、観測した胴体の移動と回転から、接地中の真ん中で基準位置に来るよう予測する（直進・曲線・その場旋回を同じ式で扱う）。届かない・固体を貫く足場は体の側へ寄せる。IK は解析解で、跗節の向きと膝の曲げ面は自動で調整する |
| 描画 | 3 段階の LOD。LOD0 は脚を動かす（最大 64 体）、LOD1 は立ち姿勢の脚を焼き込み、LOD2 は簡略形。触角は歩行中に左右に振る |
| 並列シミュレーション | エージェントを共有メモリに置き、最大 8 スレッドでスロットの範囲を分担する。結果は 1 スレッドとビット単位で一致する |
| 地形の追加 | `solidAt(x, y, z)`：その点が固体の中かを判定する（落葉の縁の下の空間は固体ではない） |
| ツール | アプリに個体追従（`antverse.followAnt`）、`browser-run.ts walk`、`scripts/make-gif.py` |
| テスト | 18 ファイル・392 件、すべて合格（81 秒） |

## 2. 合格基準の達成状況

基準は「三脚歩行で凹凸のある地形を歩き、脚が地面にめり込まない・浮かない」です。

24 体を 1.8 m 四方のアリーナで 20 秒間（28,800 回のリグ更新、172,800 脚フレーム）自由に歩かせ、毎 tick 測りました。歩いた場所には裸地・礫・落葉・草むらが混ざり、14.8% のフレームでは物体（粒・小石・葉）の上にいました（`src/locomotion/gait.test.ts`）。

| 項目 | 基準 | 結果 |
|---|---|---|
| 立脚中の足と表面の距離 | ±0.02 mm 以内 | ✅ **最大 0 mm** |
| 立脚中の足の滑り | 0.02 mm 以内 | ✅ **0 mm** |
| 遊脚の足が表面より下に入る | 0 | ✅ 0（5,509 回は、表面に沿って持ち上げて回避した） |
| 足首が固体の中に入る | 0 | ✅ 0 |
| 膝が固体の中に入る | 0.05% 未満 | ✅ 0.045%（77 回。いずれも大きな小石・葉の縁に胴体が接した状況。登る動きが範囲外のため残る） |
| 脚が届かない（伸びきり） | 1% 未満 | ✅ 0.67% |
| 三脚の交代 | 2 組が同時に遊脚にならない | ✅ 違反 0。接地している脚は常に 3 本以上 |
| 胴体のめり込み | 0.1% 未満 | ✅ 0.094%（最大 1.6 mm。上と同じく大きな物体の縁） |
| 平地での合成テスト | 伸びきりゼロ | ✅ 直進・曲線（1.6 rad/s）・その場旋回（3 / 6 rad/s）のすべてで 0。脚の長さの 77〜85% 以内 |

## 5. Phase 3 に進む前に判断していただきたいこと

Phase 3 は、フェロモンと二重橋実験です。

1. **二重橋の実験装置の作り方**: 文献（Goss 1989、Beckers 1992）の実験は、巣と餌場を 2 本の橋でつなぐ人工的な装置です。地形の上にこれを再現する方法は 2 つ考えられます。
   - (a) 装置そのもの（細い橋と、それ以外は通れない地面）を作る
   - (b) 地形の上に 2 本の経路を障害物で作る

   **(a) の専用シナリオ**（地形パラメータを差し替えたプリセット）を推奨します。合格判定のヘッドレス統計実験も、こちらの方が明確になります。
2. **道しるべフェロモンの付け方**: ASM-SPC-001 に従い、ヤマアリ亜科の *Lasius niger* の知見で補います。餌を持って帰る個体が付け、往路でも少し付けるかどうかは、二重橋が短い経路に収束するかに直接効きます。**往路にも少し付ける**ことを推奨します（Beckers 1992 の傾向）。
3. **「試行の大多数で収束」の数値基準**: 試行数と閾値を決めさせてください。
   - 提案: 50 試行。各試行で、終了時に短い経路を通る交通量の割合が 80% を超えれば「短い経路に収束」とし、それが試行の 80% 以上で起きれば合格。

## 既知の制約

- 背丈より高い障害物（大きな小石、葉の反り上がった縁）は登らずに避けます。そのとき胴体が縁に触れて、膝の 0.045% と胴体の 0.094% が固体に接します。垂直面の歩行（草を登る動きを含む）を入れる段階で解消する予定です。
- 草の葉は歩行の障害物として扱っておらず、アリは葉の根元をすり抜けます（Phase 2 の範囲外）。
- GitHub Pages とスマホでは共有メモリが使えないため、シミュレーションは 1 スレッドで動きます（2,000 体で約 6 ms/tick。スマホでは実時間より遅くなることがあります）。
